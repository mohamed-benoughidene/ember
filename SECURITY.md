# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Ember, please report it privately. Do not open a public issue.

Prefer the fastest private channel first:

- **GitHub:** open a private vulnerability report from the repository's **Security** tab.
- **Email:** alternatively write to:
**mohamedbenoughidene@gmail.com**

Please include:
- The Ember version you are running (`pip show ember`, or the `__version__` line in `ember/__init__.py`; the version matters because schema floors and behavior differ between versions).
- A description of the issue.
- Steps or a proof-of-concept to reproduce it.
- The potential impact of the issue.

You will receive an acknowledgement within 48 hours. We will work with you to understand and fix the issue before public disclosure.
