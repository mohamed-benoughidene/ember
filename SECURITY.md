# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Ember, please report it privately. Do not open a public issue.

Send an email to:
**mohamedbenoughidene@gmail.com**

Please include:
- A description of the issue.
- Steps or a proof-of-concept to reproduce it.
- The potential impact of the issue.

You will receive an acknowledgement within 48 hours. We will work with you to understand and fix the issue before public disclosure.
